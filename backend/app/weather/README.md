# Dominio meteorológico

Estado: scaffold; sin proveedores conectados.

Responsabilidad prevista: ingestión de observaciones, pronósticos y productos radar publicados o licenciados. Conservar modelo, unidades, área, periodo válido, hora de emisión/ingestión, resolución, proveedor y calidad.

Acciones: capas de precipitación/nubes/viento si la licencia lo permite, timeline, estado de fuente y alertas basadas en reglas explicables. Un pronóstico no se presenta como observación; la plataforma no sustituye servicios meteorológicos oficiales.
