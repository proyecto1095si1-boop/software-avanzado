# Dominio de observación terrestre

Estado: scaffold; no hay catálogo ni descarga de imágenes.

Alcance futuro: integrar catálogos y escenas de proveedores públicos, comerciales o institucionales con autorización; consultar metadatos, huella geográfica, timestamp, resolución, nubes, sensor, licencia y atribución. Descargas y mosaicos obedecerán términos y controles de volumen.

No implica acceso a imágenes en tiempo real, capacidades de resolución no provistas por el sensor ni imágenes de satélites fuera del acceso autorizado. Procesamientos derivados se etiquetan como tales y preservan versión del algoritmo.
