# Adaptadores SatCom autorizados

Estado: no hay proveedor conectado. Integraciones futuras deben usar una API del operador/ground station autorizada o una fuente abierta/licenciada. Documentar titular, finalidad, servicio/estación, formato, derechos, límites, retención y acceso a secretos.

Solo ingestar datos de misión que la fuente habilite explícitamente. Validar firma/esquema si el proveedor lo ofrece y preservar timestamp de adquisición, estación, calibración y calidad. No buscar enlaces privados, evadir cifrado, capturar comunicaciones ajenas ni transmitir al satélite.
