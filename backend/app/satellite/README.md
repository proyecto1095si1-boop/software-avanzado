# Dominio satelital/orbital

Implementado: CelesTrak TLE, caché, propagación, posiciones, trazas y pases básicos. El motor calcula posiciones desde elementos orbitales; eso no es telemetría real ni acceso al payload transmitido.

Siguiente: procedencia/edad/calidad de TLE, comparación de fuentes autorizadas, incertidumbre del cálculo y pruebas de propagación. No interceptar ni descifrar enlaces privados/protegidos ni transmitir comandos.
