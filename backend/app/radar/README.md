# Dominio radar

Estado: scaffold; no controla ni recibe señales de un radar.

Se contemplan dos productos distintos: mosaicos/productos de radar meteorológico publicados por proveedores y tracks ya procesados que una organización comparte mediante API/licencia. Un radar primario operacional requiere hardware, integración y aprobación del operador; no se controla desde este panel en la primera versión.

Acciones futuras: visualizar productos temporales con leyenda/unidades, procedencia, georreferencia, latencia y cobertura; consumir tracks de un proveedor autorizado; monitorizar salud de la fuente. No incluye interferencia, engaño, jamming, explotación de protocolos ni control de radar.
