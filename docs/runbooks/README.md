# Runbooks operativos pendientes

Antes de una operación productiva crear procedimientos versionados para: despliegue/rollback, restauración, rotación y revocación de credenciales, caída de cada fuente, pérdida de conexión del agente, dato obsoleto, acceso sospechoso, incidente de privacidad, exportación autorizada y contacto de proveedor.

Cada procedimiento debe indicar responsable, señales/alertas, pasos reversibles, verificación posterior y escalamiento. No documentar secretos ni valores reales de infraestructura.
