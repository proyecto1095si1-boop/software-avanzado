# Modelo de amenazas pendiente

Activos: identidad, cámaras/inventario, metadatos de vuelo/satélite, video autorizado, secretos, reglas AOI, auditoría y disponibilidad.

Límites: navegador/API, API/base de datos, conectores/terceros, nube/VMS, agente de borde y VLAN del propietario. Amenazas a evaluar: IDOR/BOLA, SSRF, cuenta comprometida, secreto expuesto, proveedor malicioso/caído, dato envenenado, replay, denegación de servicio, abuso interno y pérdida de backup.

Antes de producción crear diagramas de flujo, escenarios y controles; revisar con el dueño de cada red/fuente. Ninguna prueba se ejecuta fuera del alcance aprobado.
