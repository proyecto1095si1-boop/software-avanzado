# Perfil edge

Estado: no implementado. Diseño futuro para conectores dentro de redes que administra el propietario, p. ej. un VMS o feed local. Requiere enrolamiento mutuo, identidad de agente, actualización firmada, egress mínimo, allowlist por scope, monitoreo, revocación y aprobación del operador. No escanear redes ni abrir puertos entrantes automáticamente.
